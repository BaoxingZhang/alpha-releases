# Built-in WeChat emoji resources

The PNG resources and alias mapping were copied from the local WeChatDataAnalysis reference: `frontend/public/wxemoji/` and `frontend/lib/wechat-emojis.ts`. The user requested reuse of this existing implementation. Resource rights remain with their respective owners.

Alpha bundles these resources and adapts token segmentation to React. No reference-repository path or network fetch is used at runtime.
